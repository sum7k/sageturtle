# Shell: idea

The shell is everything around the 13 apps: the install page, the first run, Home, and the profile switch. Every app sits inside it.

The drawn screens are at https://claude.ai/artifact/Jgem7AE3dhZSPvVkV6bqS1. The screen-by-screen description is in `docs/screens.md`.

## What it must do

- A person can install it, set it up and use it alone, in their own language. Words are few and plain (changed 2026-11-28: no voice; before that the shell was wordless and spoke).
- The first run is five screens and is the registration. Nothing has to be typed except the PIN code on a number pad.
- The fingerprint or face is the only key. There is no password, no phone number and no OTP.
- Home at launch: the ad spot on top, then 11 buttons. Book, Horoscope and Khabri are open; eight are locked and count taps. (After all apps open: the apps of the person's variant, with that variant's names.)
- A child cannot leave the child's profile without the owner.
- It looks like Khabri: sky ground, navy ink, gold for the main action, soft tints, round cards, pills.

## The order

1. Landing page (in the browser). Only one action: install. A picture shows where to tap in that browser.
2. Language. 11 blocks.
3. Lock. Set the fingerprint or face. This creates the account.
4. PIN code.
5. What you do. 9 picture blocks for adults.
6. Khabar alerts. Yes or not now.
7. Home.
8. Profiles, opened from Home. This is the door to Me.
